# Практические работы по дисциплине «Фронтенд и бэкенд разработка»

Практические задания разделены по веткам репозитория.


## Практическое задание 19 

Реализован бэкенд на основе Express.js, который представляет собой CRUD операции с пользователем. База данных реализована с помощью postgres с ипсользованием Sequelize ORM.

## Практическое задание 20 

Переписана часть бэкенда связанная с хранением пользователей (хранение данных реализовано на MongoDB).
