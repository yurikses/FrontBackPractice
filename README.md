# Практические работы по дисциплине Фронтенд и бэкенд разработка
Практические задания разделены по веткам репозитория

## Практическое задание 9

Добавлен refresh token для обновления access token. Функция `refreshToken` принимает refresh token и возвращает новый access token, если refresh token действителен. Это позволяет пользователю оставаться аутентифицированным без необходимости повторного входа в систему после истечения срока действия access token.

## Практическое задание 10 

Добавлен функционал для рефреша токена. В бэкенде добавлен новый маршрут `/refresh`, который принимает refresh token и возвращает новый access token, если refresh token действителен. На фронтенде добавлена функционал отправки запроса на обновление токена при истечении срока действия access token.

### Фронтенд
 Для запуска перейти в папку frontend и выполнить команду `pnpm install` для установки зависимостей, а затем `pnpm dev` для запуска приложения
 
### Бэкенд
  Для запуска перейти в корневую папку и выполнить команду `npm install` для установки зависимостей, а затем `npm start` для запуска приложения
