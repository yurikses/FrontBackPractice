# Практические работы по дисциплине «Фронтенд и бэкенд разработка»

Практические задания разделены по веткам репозитория.

# Практическая работа №15-16

Добавлена поддержка HTTPS подключения, включающая в себя создание и подключение SSL-сертификатов. Реализована полноценная система Push-уведомлений:
- Развернут отдельный backend-сервер на Node.js для рассылки уведомлений с использованием библиотеки `web-push`.
- Настроена двусторонняя связь через **WebSocket** (`socket.io`) для мгновенного обмена сообщениями о новых задачах между клиентами (In-App уведомления).
- Внедрен **Service Worker** (`sw.js`) для фонового перехвата системных Push-сигналов и отображения уведомлений на уровне операционной системы, даже когда вкладка браузера закрыта.
- Реализована генерация и использование VAPID-ключей для безопасной аутентификации сервера пуш-уведомлений.

# Практическая работа №17-18 

Реализовано отложенное планирование задач и интерактивные действия с уведомлениями:
- Добавлена форма для создания заметки с напоминанием (выбор даты и времени через `datetime-local`).
- Изменена структура хранения данных в `localStorage`: теперь заметки включают уникальный идентификатор (`id`) и время напоминания (`reminder` в формате timestamp).
- На сервере реализовано планирование Push-уведомлений с помощью `setTimeout` и `Map` для надежного хранения активных таймеров. Сервер автоматически вычисляет задержку и отправляет уведомление строго в назначенное время.
- В Service Worker добавлена обработка действий (Actions): в системном уведомлении появилась кнопка **«Отложить на 5 минут»** (`snooze`).
- При нажатии на кнопку "Отложить", Service Worker автономно (в фоновом режиме) отправляет запрос на сервер для переноса напоминания, а сервер заводит новый таймер на 5 минут.
