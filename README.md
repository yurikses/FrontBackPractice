# Практические работы по дисциплине Фронтенд и бэкенд разработка
Практические задания разделены по веткам репозитория

## Практическое задание 7

Добавлены простые функции для создания хеша пароля и его проверки. В данном случае используется bcrypt, который является популярной библиотекой для хеширования паролей. Функция `hashPassword` принимает пароль и возвращает его хеш, а функция `verifyPassword` принимает пароль и хеш и проверяет, соответствует ли пароль хешу.

## Практическое задание 8 

Добавлены функции для генерации и проверки JWT (JSON Web Tokens). Функция `generateToken` принимает данные пользователя и возвращает JWT, который можно использовать для аутентификации. Функция `verifyToken` принимает JWT и проверяет его валидность, возвращая данные пользователя, если токен действителен.

### Фронтенд
 Для запуска перейти в папку frontend и выполнить команду `pnpm install` для установки зависимостей, а затем `pnpm dev` для запуска приложения
 
### Бэкенд
  Для запуска перейти в корневую папку и выполнить команду `npm install` для установки зависимостей, а затем `npm start` для запуска приложения
